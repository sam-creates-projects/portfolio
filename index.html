HyperVector — C++20, ARM NEON, HNSW repo ↗

HyperVector — Sub-Millisecond SIMD Vector Search Engine

HNSW-graph vector index with hand-written 128-bit NEON SIMD intrinsics — sub-millisecond retrieval at real scale.

21,750+ QPS0.046ms latency99.4% recall@10

How it works

Query enters at the top layer of a multi-layer HNSW graph and greedily descends toward nearest neighbors, with NEON intrinsics computing 4 dot-products per CPU cycle at each hop.

AutoPatch — Python, AST repo ↗

AutoPatch

Agentic CI/CD debugger that localizes failing tests via AST traversal and synthesizes verified patch diffs.

100% pass@10.15s/fix

How it works

Parses the failing trace into an AST, localizes the faulty node, and synthesizes a patch that's validated against the full test suite before it's ever proposed.

EdgeDepth-MPS — PyTorch, MPS repo ↗

EdgeDepth-MPS

Real-time monocular-to-3D vision — depth estimation unprojected into dense point clouds on Apple Metal GPU.

46.8 FPS21.3ms

How it works

MobileDepthNet predicts per-pixel depth from a single RGB frame; each pixel is then unprojected through the camera's intrinsic matrix into a 3D point cloud, entirely on-device.

Stack: PyTorch, Apple MPS, NumPy, Open3D.

EchoStream — Apple MLX repo ↗

EchoStream

Full-duplex on-device voice AI with barge-in interruption handling — conversational latency low enough to feel human.

23.66ms<40ms interrupt

How it works

An energy-based voice activity detector watches the mic in 20ms windows; the moment it detects speech during playback, it kills the TTS stream and starts listening — all within one frame.

Stack: Apple MLX, WebSockets, asyncio.

NeuroScan-3D — 3D-UNet, BraTS repo ↗

NeuroScan-3D

Multi-modal MRI brain tumor segmentation with multi-planar reconstruction across four imaging sequences.

94.1% Dice (WT)92.4% (TC)

How it works

Four MRI sequences (T1, T1ce, T2, FLAIR) are stacked as input channels to a 3D-UNet, which segments whole tumor, core, and enhancing regions directly in volumetric space.

Stack: PyTorch, 3D-UNet, NiBabel.

NeuroBlink — SNN, Event Cameras repo ↗

NeuroBlink

Neuromorphic spiking neural network for drone collision evasion, processing microsecond event-camera spikes directly.

2.88ms evasion1,000x finer res.

How it works

Event-camera spikes are rasterized into voxel grids and fed to leaky integrate-and-fire neurons; a spike train — not a frame — triggers the evasion controller directly.
